### ch01-q1 | mcq | 2025 Exam Q1
Which type of cost associated with a programming language is the most relevant in a modern computing context?
- [ ] Cost of compiling programs.
- [ ] Cost of executing programs.
- [x] Cost of reliability.
- [ ] Cost of the language implementation system.
> Hardware is cheap and fast and free compilers are common, so compile/execute/implementation costs matter less. Failures in reliable systems (and the people costs of fixing them) dominate.

### ch01-q4 | mcq | Practice
Which definition of orthogonality is most complete?
- [ ] A language has a small number of primitive constructs.
- [ ] A language supports many ways to perform the same operation.
- [x] A relatively small set of primitive constructs can be combined in a relatively small number of ways, and every possible combination is legal.

> A small set of constructs alone is not enough — every combination must be legal (no exceptions).

### ch01-q8 | mcq | Practice

- [ ] Readability vs writability
- [x] Reliability vs cost of execution
- [ ] Writability vs reliability
- [ ] Portability vs generality

### ch01-q9 | mcq | Practice
Which characteristic of the von Neumann architecture makes iteration efficient in imperative languages?
- [ ] Data and instructions are stored in separate memories.
- [x] Instructions are stored in adjacent memory cells and piped from memory to the CPU.
- [ ] The CPU supports recursion in hardware.
- [ ] Variables are stored inside the CPU.
> Repeating instructions in adjacent cells is fast; recursion is comparatively discouraged.

### ch01-q10 | mcq | Practice
Which statement about pure interpretation is correct?
- [ ] It translates programs into machine code once, before execution.
- [x] It allows run-time errors to be reported easily in terms of the source program, but executes 10–100 times slower than compiled code.
- [ ] It uses less memory than compilation because no symbol table is kept.
- [ ] It is the most common method for traditional high-level languages today.
> Interpretation decodes statements repeatedly (slow) and keeps the source and symbol table at run time (more space).

### ch01-q11 | mcq | Practice
What is a Just-in-Time implementation system?
- [ ] A pure interpreter that caches the source program.
- [ ] A compiler that compiles the whole program at load time.
- [x] A hybrid system that compiles each subprogram's intermediate code to machine code when it is first called, and keeps it.
- [ ] A preprocessor that expands macros before compilation.
> JIT = delayed compilation per subprogram; used for Java and .NET.
