### ch02-q1 | mcq | 2026 Exam Q1
Which option most correctly describes the programming methodology influence that affected the design of SIMULA 67?
- [ ] A focus on simple applications and machine efficiency.
- [ ] Programmer efficiency becoming more important than machine efficiency.
- [x] The move from process-oriented programming to data-oriented programming.
- [ ] The introduction of object-oriented programming.
> Study answer (your choice, "introduction of OOP", was marked wrong). SIMULA 67 introduced classes — the **beginnings of data abstraction** — which belongs to the shift to data-oriented design; it was not full OOP (that's Smalltalk, mid-1980s methodology).

### ch02-q2 | mcq | 2026 Exam Q2
In which programming language is the design most orthogonal?
- [ ] PL/I
- [ ] ALGOL 60
- [ ] C++
- [x] Smalltalk
> Study answer (ALGOL 60 was marked wrong). Smalltalk has a tiny set of concepts — everything is an object and all computation is message passing — combined uniformly. PL/I and C++ are large with many special cases.

- [x] The IBM 704 had floating-point and indexing hardware, so the cost of interpretation could no longer be hidden.

### ch02-q11 | mcq | 2025 Exam Q4
Which language focused the most on the well-definedness of its original language design?
- [ ] Fortran I
- [x] ALGOL 68
- [ ] C
- [ ] C++
> ALGOL 68 was rigorously defined (Van Wijngaarden grammar). Fortran I, C and C++ had informal early definitions (C wasn't standardised until 1989).
