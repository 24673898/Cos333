### ch06-q1 | mcq | 2026 Exam Q6
Which statement about rectangular and jagged arrays is most correct?
- [x] Rectangular arrays are less orthogonal than jagged arrays.
- [ ] Any jagged array can be easily translated into a rectangular array.
- [ ] Rectangular arrays are less readable than jagged arrays.
- [ ] Java is more flexible in its support of rectangular and jagged arrays than C# is.
> Study answer (the "easily translated" option was marked wrong — rows of different lengths don't fit a rectangle). A jagged array is just the free combination "an array whose elements are arrays"; a rectangular array is an extra special-purpose construct → less orthogonal. Java has only jagged arrays; C# has both.
