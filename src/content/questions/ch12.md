### ch12-q1 | multi | 2026 Exam Q26
A language supports multiple inheritance. Classes B and C both inherit from A; class D inherits from both B and C. Select **only** the classes in which implementing a method named `operation` leads to an **implicit** name collision. (Wrong selections are penalised.)
- [x] Class A.
- [ ] Class B.
- [ ] Class C.
- [ ] Class D.
> Study answer (selecting Class C was marked wrong). A method in A reaches D through **two paths** (via B and via C) without D's programmer writing anything — the implicit diamond collision. Defining it only in B (or only in C) gives D a single copy; defining it in D just overrides.

### ch12-q13 | mcq | Practice
Why are Java interfaces simpler than C++ multiple inheritance?
- [x] Interfaces contain only method declarations and named constants, so no implementations or data can collide.
- [ ] Interfaces can't be implemented by more than one class.
- [ ] Interfaces are resolved at compile time only.
- [ ] Interfaces don't support polymorphism.
