### ch15-q10 | fill | Practice
What does this yield?
```scheme
(define (mystery lis)
  (cond
    ((null? lis) '())
    ((odd? (car lis)) (mystery (cdr lis)))
    (else (cons (* 3 (car lis)) (mystery (cdr lis))))))
(mystery '(1 2 3 4))
```
= (6 12)
> Odd values are skipped; even values are tripled: 2 → 6, 4 → 12.

### ch15-q11 | fill | Practice
What does `(adder '(3 4 5))` yield?
```scheme
(define (adder lis)
  (cond
    ((null? lis) 0)
    (else (eval (cons '+ lis)))))
```
= 12
> `(cons '+ lis)` builds the code `(+ 3 4 5)`, which `eval` then evaluates.

```scheme
(define (monotonic lis)
  (cond
    ((null? lis) #t)
    ((> (car lis) (car (cdr lis))) #f)
    (else (monotonic (cdr lis)))))
```
- [ ] It yields `#t`.
- [ ] It yields `#f`.
- [x] It produces an error.
- [ ] It loops forever.
> `(cdr '(5))` is `()`, and `(car '())` is an error. A compare-neighbours function needs a `(null? (cdr lis))` base case.
