- [ ] The query is definitely false.
- [x] The query could not be proven from the facts and rules.

- [x] All variables on the right must be instantiated; the left variable must not be.

### ch16-q13 | fill | Practice
How many solutions does `?- p([1, -2, 3], X).` give (counting re-queries), for this unguarded program?
```prolog
p([], []).
p([H|T], [H|R]) :- p(T, R).
p([H|T], R) :- H < 0, p(T, R).
```
= 2
> Without a guard on the second rule, the −2 can be either kept (rule 2) or removed (rule 3): X = [1, -2, 3] and X = [1, 3]. Guards prevent such invalid instantiations.
